# 要件定義：世界の人工衛星から

状態：ドラフト｜作成日：2026-10-14｜最終確認者：【要確認】

## 1. 概要

世界の気象衛星が撮った地球の最新画像を、約10分ごとに更新して表示するミニ Web アプリ。v1 ではひまわり9号、GOES-East、GOES-West の3つを切り替えて見られる。どの画像にも、どの衛星がいつ撮ったかを添える。

## 2. 背景・課題

- 対象ユーザー：作者本人と、その知人
- 現状：衛星画像は気象機関や研究機関のサイトで公開されている。ただしサイトごとに見た目も使い方も違い、専門家向けのものが多い
- 課題：「今の地球」を気軽に眺めるには手間が多い。複数の衛星の画像を、同じ画面で切り替えて見たい

## 3. ユーザーとロール

| ロール | 説明                                               | できること                       |
| ------ | -------------------------------------------------- | -------------------------------- |
| 閲覧者 | URL を知っている人（作者と知人）。ログインはしない | 最新画像を見る、衛星を切り替える |

## 4. ユーザーストーリー

優先度：P1＝MVPに必須／P2＝早期に欲しい／P3＝将来

### ストーリー1：今の地球を見る（P1）

閲覧者として、今の地球の様子を楽しむために、アプリを開いたらすぐ衛星の最新画像を見たい。

**なぜこの優先度か**：アプリの存在理由そのものだから。

**受け入れシナリオ**

1. **Given** 配信元が正常、**When** アプリを開く、**Then** 前回選んだ衛星（初回はひまわり9号）の最新の地球全体画像が表示され、衛星名と撮影日時が見える
2. **Given** スマホの 4G 回線、**When** アプリを開く、**Then** 3秒以内に画像が表示される
3. **Given** 初回の取得に失敗した、**When** アプリを開く、**Then** 空白にはならず、取得できなかったことが表示される。次の周期（10分後）で自動的にやり直す

### ストーリー2：衛星を切り替える（P1）

閲覧者として、世界のいろいろな場所を見るために、衛星を切り替えたい。

**なぜこの優先度か**：「世界の人工衛星から」というコンセプトの核だから。

**受け入れシナリオ**

1. **Given** ひまわり9号の画像を表示中、**When** GOES-East を選ぶ、**Then** GOES-East の最新画像に替わり、衛星名と撮影日時も GOES-East のものになる
2. **Given** 切り替え先の取得に失敗した、**When** 衛星を選ぶ、**Then** 切り替え前の衛星の画像は消え、選んだ衛星の名前と「取得できませんでした」が表示される。次の周期で自動的にやり直す

### ストーリー3：開いたまま最新に保たれる（P1）

閲覧者として、画面を開きっぱなしで眺めるために、操作しなくても画像が新しくなってほしい。また、画像が古いときはそれと分かるようにしてほしい。

**なぜこの優先度か**：「リアルタイム」の体験を支える部分で、失敗したときの振る舞いを最初から決めておく必要があるから。

**受け入れシナリオ**

1. **Given** 画像を表示中、**When** 10分たち、配信元に新しい画像がある、**Then** 新しい画像と撮影日時に差し替わる
2. **Given** 画像を表示中、**When** 更新の取得に失敗する、**Then** 前の画像を残したまま「更新できませんでした」と表示され、次の周期で再試行する。成功したら表示が消える
3. **Given** 衛星のメンテナンスなどで、最新の画像の撮影日時が60分以上前、**When** その画像を表示する、**Then** 画像は表示したまま「○分前の画像です」と注意が出る

### ストーリー4：拡大して見る（P1。2026-10-15 に P2 から引き上げ）

閲覧者として、雲や台風の細部を見るために、全球画像を拡大・移動したい。

**なぜこの優先度か**：作者が「もっとアップの写真を見たい」と求めたため（2026-10-15）。

**受け入れシナリオ**

1. **Given** ひまわり9号の全球画像を表示中、**When** 拡大する（＋ボタン、ピンチ、ダブルタップ、ホイール）、**Then** その場所が、より細かい画像で大きく表示される
2. **Given** 拡大中、**When** ドラッグする、**Then** 表示する場所が動き、新しく見えた部分の画像が読み込まれる
3. **Given** 拡大中、**When** 10分たち、新しい画像がある、**Then** 同じ場所・同じ倍率のまま新しい画像に替わる

### ストーリー9：地域を大きく見る（P1。2026-10-15 追加）

閲覧者として、日本や北米など見たい地域をすぐ見るために、衛星ごとに用意された地域を選びたい。

**受け入れシナリオ**

1. **Given** ひまわり9号を表示中、**When** 「日本」を選ぶ、**Then** 日本付近を大きく写した画像が表示される。撮影日時は全球と同じ
2. **Given** 地域を表示中、**When** 「全球」を選ぶ、**Then** 地球全体の表示に戻る
3. **Given** 地域を表示中、**When** 別の衛星を選ぶ、**Then** その衛星の全球の表示になる

### ストーリー10：宇宙から見た地球（P1。2026-10-15 追加）

閲覧者として、宇宙に浮かぶ地球の姿を見るために、宇宙を背景にした地球全体の写真を見たい。

**受け入れシナリオ**

1. **Given** アプリを表示中、**When** 「宇宙から（DSCOVR）」を選ぶ、**Then** 黒い宇宙を背景にした、昼側の地球全体の写真が表示され、撮影日時と「公開まで1〜2日かかる」旨が見える
2. **Given** 「宇宙から」を表示中、**When** 取得に失敗する、**Then** ストーリー1〜3と同じ失敗の表示になる

### ストーリー5：直近の雲の動きを見る（P2）

閲覧者として、雲や台風の動きを楽しむために、直近数時間の画像をタイムラプスで再生したい。

### ストーリー6：全画面で眺める（P2）

閲覧者として、スクリーンセーバーのように眺めるために、画像を全画面で表示したい。

### ストーリー7：過去の日付の画像を見る（P3）

### ストーリー8：赤外・水蒸気などの観測バンドに切り替える（P3）

## 5. 機能要件

| ID     | 要件                                                                                                                                                                                                                                                  | ストーリー |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| FR-001 | アプリを開いたとき、前回選んだ衛星（初回はひまわり9号）の最新の地球全体画像（GeoColor：昼は自然な色、夜は街明かりの合成）を表示する。選んだ衛星は端末に保存する                                                                                       | 1          |
| FR-002 | 表示中の画像の近くに、衛星名と撮影日時を表示する。撮影日時は端末のタイムゾーンで、タイムゾーン名を添えて表示する                                                                                                                                      | 1, 2       |
| FR-003 | 衛星はひまわり9号、GOES-East、GOES-West の3つから選べる。選んだとき、画像・衛星名・撮影日時がその衛星の最新のものに替わる                                                                                                                             | 2          |
| FR-004 | 画像を表示している間、10分ごとに最新画像を確認する。撮影日時が新しくなっていれば画像を差し替え、同じなら何もしない                                                                                                                                    | 3          |
| FR-005 | 更新の取得に失敗したとき、表示中の画像を残したまま「更新できませんでした」と表示する。次の周期で再試行し、成功したら表示を消す                                                                                                                        | 3          |
| FR-006 | 表示できる画像がない状態で取得に失敗したとき、空白のままにせず、取得できなかったことを表示する。再試行は FR-005 と同じ周期で行う                                                                                                                      | 1          |
| FR-007 | 表示中の画像の撮影日時が現在時刻より60分以上前のとき、「○分前の画像です」と表示する。60分未満のときは表示しない                                                                                                                                       | 3          |
| FR-008 | クライアントが読み込む画像は、長辺 2000px 以下とする                                                                                                                                                                                                  | 1          |
| FR-009 | サーバー関数 `/api/latest?satellite=<ID>` は、指定された衛星の最新画像 URL、撮影日時、衛星名、クレジット表記を返す。結果は約5分キャッシュする                                                                                                         | 1, 2, 3    |
| FR-010 | `/api/latest` に許可リストにない衛星 ID が指定されたとき、配信元には問い合わせずに 400 を返す                                                                                                                                                         | 2          |
| FR-011 | `/api/latest` で配信元が失敗またはタイムアウトしたとき、5xx 系のエラーを返す。クライアントはそれを FR-005／FR-006 の失敗として扱う                                                                                                                    | 3          |
| FR-012 | 配信元の利用条件でクレジット表記が求められている場合、画面にクレジットを表示する【要確認：表記は仮置き。§9 参照】                                                                                                                                     | 1          |
| FR-013 | 衛星ごとに「全球」と地域を選べる。地域は全球画像の一部を拡大した表示で、撮影日時は全球と同じ。地域の一覧（仮置き）：ひまわり9号＝日本・オーストラリア、GOES-East＝北米・南米、GOES-West＝北米西部・ハワイ                                             | 9          |
| FR-014 | 全球画像と地域の表示を、＋／−ボタン・ピンチ・ダブルタップ・ホイールで5段階に拡大でき、ドラッグで移動できる。表示に必要な範囲のタイル（1枚の長辺 700px 以下）だけを読み込む                                                                            | 4          |
| FR-015 | 拡大中や地域の表示中に新しい画像に替わるときは、表示する場所と倍率を保つ                                                                                                                                                                              | 4, 9       |
| FR-016 | 「宇宙から（DSCOVR）」を選ぶと、NASA EPIC の最新の自然色画像（1080px）を表示する。撮影日時と「公開まで1〜2日かかります」の注記を出す。撮影から72時間以上たっているときは「○時間前の画像です」と注意を出す（しきい値は仮置き）。拡大と地域の選択はない | 10         |
| FR-017 | 「宇宙から」のクレジットは「NASA EPIC Team」と表示する                                                                                                                                                                                                | 10         |

## 6. エッジケース・異常系

- 通信断・配信元の障害：FR-005、FR-006
- 衛星のメンテナンスなどで画像が古い：FR-007
- 撮影日時が取れない・形式が不正：取得失敗として扱う
- 不正な衛星 ID：FR-010
- 夜の側：3衛星とも GeoColor（昼は自然な色、夜は街明かりなどの合成）を使う（2026-10-14 決定。プラン latest-image-api）
- タブが裏にあるとき：更新を止め、表に戻ったらすぐ確認する（前回の確認から1分以内なら待つ）
- 更新の確認中に衛星を切り替えた：古い衛星の取得結果で画面を上書きしない

## 7. 非機能要件

| 区分         | 要件                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 性能         | スマホの 4G 回線でも、初回の画像表示まで3秒以内                                                                                |
| 鮮度         | 表示中の画像は、配信元で公開済みの最新画像から最大でも約15分遅れ（10分ごとの確認＋5分のキャッシュ）                            |
| セキュリティ | 個人情報は扱わない。ログインなし。API キーなし。サーバー関数は許可リストの配信元にしかアクセスしない（docs/rules/security.md） |
| コスト       | 月額0円（Cloudflare の無料枠内）。配信元が止まったらアプリも止まることは許容する                                               |
| 公開範囲     | URL を知っている人だけが使う想定。検索エンジン対策や大量アクセスへの対策はしない                                               |
| 対応環境     | スマホとPCの主要ブラウザ（Chrome、Safari）【要確認：対応する範囲の細部】                                                       |

## 8. データ（主要エンティティ）

サーバー側では永続化しない。端末（ブラウザの localStorage）には、選んだ衛星の ID だけを保存する。

| エンティティ            | 主な属性                                     | 関連                                   |
| ----------------------- | -------------------------------------------- | -------------------------------------- |
| 衛星（Satellite）       | ID、表示名、担当地域、配信元、クレジット表記 | サーバー側で固定の許可リストとして持つ |
| 最新画像（LatestImage） | 衛星 ID、画像 URL、撮影日時（UTC）、取得日時 | 衛星 1 : 1（その時点の最新）           |

## 9. 外部連携

- 撮影日時：3衛星とも CIRA SLIDER の `latest_times.json`（約2.4KB）から取る。API キー・登録は不要
- GOES-East（GOES-19）／GOES-West（GOES-18）：画像は NOAA STAR CDN の GeoColor（339／678／1808px）。CIRA の時刻から STAR のファイル名を組み立て、678px に HEAD を送って公開済みかを確かめる
- ひまわり9号：画像は CIRA SLIDER の GeoColor（688px の1枚）
- 拡大と地域：3衛星とも CIRA SLIDER の全球画像の拡大タイル（z0〜z4 の5段階。z の段では 2^z × 2^z 枚。1枚はひまわり 688px、GOES 678px。URL は `…/{撮影時刻}/{zz}/{行}_{列}.png`）。撮影日時は全球と同じ `latest_times.json` から取る
- 宇宙から：NASA EPIC の `https://epic.gsfc.nasa.gov/api/natural`（最新日の一覧、キー不要）と、`/archive/natural/YYYY/MM/DD/jpg/<image>.jpg`（1080px、約210KB）
- 画像は配信元を直接参照する（Functions で中継しない）
- 外部 API・Cloudflare は無料の範囲だけで使う。詳細と根拠は `.claude/plans/latest-image-api.md`
- 【要確認】利用条件：外部サイトからの画像の直接参照の可否と、クレジット表記（仮置き：GOES＝`NOAA/NESDIS/STAR, CSU/CIRA`、ひまわり＝`CSU/CIRA & JMA`）。公開前に作者が確認する

## 11. スコープ外

v1では扱わないもの。AIが「ついでに」作らないための明記。

- ログイン・アカウント
- 画像の保存・ダウンロード・SNS 共有
- ひまわり9号、GOES-East、GOES-West、DSCOVR（EPIC）以外の衛星（Meteosat など）
- ISS など、リアルタイムでない過去の写真
- タイムラプス、全画面（P2。v1 の後に検討）
- 「宇宙から」の拡大と地域の選択
- 過去日付の画像の検索、赤外・水蒸気などの観測バンドの切り替え（P3）
- 動画のライブ配信（ISS のライブカメラなど）
- 一般公開向けの対策（検索エンジン対策、大量アクセスへの対策）
